# Backend modules

Plain Laravel folders. No nwidart package.

| Folder | Phase 1 |
|---|---|
| Identity | OTP login, roles |
| Workers | Profile, KYC, skills, availability |
| Catalog | 4 seeded categories |
| Marketplace | service_requests, assignments |
| Events | Create event, attendance, replace |
| Tasks | `task_details` table only |
| Money | Manual/dev pay, ledger, payouts |
| Trust | Ratings, reports |
| Ops | Admin KYC, fill board, audit |

Shared user model: `App\Models\User`.
